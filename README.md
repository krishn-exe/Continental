
# The Continental hotel management tool

A smart and user-friendly Python + Tkinter + MySQL hotel management application designed to simplify bookings, guest management, room tracking, and check-in/check-out operations—all in one place.


## Deployment

To run this open the main.py python file

```bash
  python main.py
```

A few MYSQL commands need to be excuted 

```bash
  MySQL> source /XII-Project/resources/SQL_cmds.sql
  ```
Make sure to install the required font(s) in the temporary folder




## Features

- Interactive and smiple GUI
- Add customer details
- Delete customer information
- Edit customer information
- View customers
- Add room details
- Clear rooms
- Book rooms 
- View rooms
